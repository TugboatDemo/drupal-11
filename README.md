# Drupal 11 Demo

This is an out-of-the-box Drupal 11 site, installed via Composer with no
custom modules, themes, or configuration beyond Drupal core defaults.

It's used as a demo/preview site with [Tugboat](https://www.tugboatqa.com/),
see [.tugboat/config.yml](.tugboat/config.yml) for the preview build
configuration.
